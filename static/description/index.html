Equipment Loan Tracker

Know who has which company equipment, since when, for how long, and what it costs.

Features

  • Equipment register: laptops, projectors, tools, safety gear and vehicles, each with a category and a daily rate.
  • Auto reference: every loan gets a unique number, e.g. LOAN/2026/00001.
  • Smart dates: enter a return date and the duration is calculated, or enter the number of days and the return date is set for you.
  • Automatic cost: total cost = duration × daily rate, with a minimum of 1 billable day.
  • Overload warning: a heads-up when an employee already has 2 or more active loans.
  • Bulk Return: select several loans, pick one return date, and close them all in one step.

Built-in checks

  • Equipment that is already out on an ongoing loan cannot be loaned again until it is returned.
  • The return date cannot be before the loan date.
  • The same employee cannot borrow the same item on the same date twice.
  • Loan duration must be at least 1 day.

Equipment categories

Category Examples
IT and Computing Laptops, monitors, tablets
Audio-Visual and Presentation Projectors, screens, speakers, microphones
Tools and Maintenance Drills, multimeters, generators
Safety and Protective Helmets, vests, harnesses, first aid kits
Vehicles and Transport Pickups, staff buses, pallet jacks

Access rights

  • Equipment Managers: see and manage all loans and equipment.
  • Regular users: see and edit only their own loans.

How to use

  1. Add equipment under Equipment Loans → Configuration → Equipment.
  2. Create a loan under Equipment Loans → Loans, choose the employee and equipment, then set the return date or the duration in days.
  3. When the item comes back, click Mark Returned.
  4. To close several loans at once, tick them in the list and use Bulk Return.
